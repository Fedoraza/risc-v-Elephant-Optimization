# Optimised Elephant-Spongent-π[160] Implementation for RISC-V

Author: Fedor Musil
Supervisor: Kostas Papagiannopoulos

This repository contains the full source code accompanying the bachelor’s
thesis:

**“Optimising the Elephant Lightweight Encryption Scheme in Assembly for
RISC-V Processors”**

The project provides a hand-written RISC-V RV32I assembly implementation
of the Elephant-Spongent-π[160] permutation, using bitslicing and
low-level optimisation techniques. The focus is on performance,
constant-time execution, and suitability for resource-constrained
embedded systems.

The code is build and run using segger embedded studio 8.24 for RISC-V proccesors

To archieve the measurements made in the thesis the main.c can be ran which contains the measurement script.
